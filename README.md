# AI Database Visualizer

A beautiful, modern web application that allows users to connect their MySQL database, chat with their data, and get instant visual insights through an AI-powered interface.

## Features

- 🎨 Modern glassmorphic UI design
- 🔄 Smooth transitions and animations
- 💬 Interactive chat interface
- 📊 Dynamic data visualization
- 📱 Fully responsive design
- 🔒 Secure database connection handling

## Technologies Used

- HTML5
- CSS3 (with modern features like backdrop-filter)
- JavaScript (ES6+)
- Chart.js for data visualization
- Remix Icons for beautiful icons

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Start exploring the interface!

## Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # All styles and animations
├── script.js           # Interactive functionality
└── README.md          # Project documentation
```

## Features in Detail

### Landing Page
- Clean, modern design with glassmorphic hero card
- Animated gradient background
- Smooth hover effects and transitions

### Database Connection
- Secure form for MySQL credentials
- Floating labels with icons
- Loading spinner for connection testing
- Error handling

### Chat Interface
- Real-time chat with AI
- Message bubbles with glassmorphic effect
- Support for Enter key to send messages
- Auto-scrolling message container

### Data Visualization
- Dynamic chart generation
- Multiple chart types (Bar, Pie, Line)
- Download chart functionality
- Responsive chart container

## Browser Support

The application works best in modern browsers that support:
- CSS backdrop-filter
- CSS Grid and Flexbox
- ES6+ JavaScript features
